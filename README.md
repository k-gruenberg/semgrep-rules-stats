# semgrep-rules-stats
A Python script generating statistics on the rules found in https://github.com/semgrep/semgrep-rules 

## Usage

```
$ git clone git@github.com:semgrep/semgrep-rules.git
$ git clone git@github.com:k-gruenberg/semgrep-rules-stats.git
$ python3 -m pip install pyyaml
$ python3 ./semgrep-rules-stats/semgrep_rules_stats.py ./semgrep-rules
```
